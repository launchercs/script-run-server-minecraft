# 🎮 راه‌اندازی خودکار سرور ماینکرفت

یک اسکریپت Bash که فرآیند راه‌اندازی سرور Minecraft Java Edition را به‌صورت خودکار انجام می‌دهد؛ شامل نصب جاوا، پیکربندی سرور و راه‌اندازی تونل Playit.gg.

---

## ✨ امکانات

- 🚀 **راه‌اندازی خودکار** — سرور ماینکرفت را به‌صورت خودکار نصب و پیکربندی می‌کند.
- ☕ **تشخیص نسخه جاوا** — بر اساس نسخه ماینکرفت، نسخه مناسب جاوا را انتخاب می‌کند.
- 📦 **نصب خودکار پیش‌نیازها** — پکیج‌ها و ابزارهای مورد نیاز را نصب می‌کند.
- 🎮 **آخرین نسخه ماینکرفت** — اطلاعات آخرین نسخه را از مانیفست رسمی موجانگ دریافت می‌کند.
- 🧠 **پیکربندی رم** — امکان تعیین مقدار رم اختصاص‌داده‌شده به سرور.
- ⚙️ **پیکربندی خودکار** — اسکریپت اجرا و فایل پایه `server.properties` را می‌سازد.
- 🌐 **یکپارچگی با Playit.gg** — تونلی برای دسترسی از راه دور به سرور راه‌اندازی می‌کند.
- 🖥️ **پشتیبانی از Screen** — سرور را در یک نشست ترمینال پایدار اجرا می‌کند.

---

## 📋 پیش‌نیازها

- یک سیستم لینوکسی سازگار با `apt-get`
- اتصال به اینترنت
- دسترسی `sudo`
- رم و فضای ذخیره‌سازی کافی
- یک حساب [Playit.gg](https://playit.gg) برای اتصال تونل

---

## 🚀 شروع کار

۱. **مخزن را کلون کنید:**
   ```bash
   git clone https://github.com/launchercs/script-run-server-minecraft.git
   ```

۲. **وارد پوشه پروژه شوید:**
   ```bash
   cd script-run-server-minecraft
   ```

۳. **اسکریپت راه‌اندازی را اجرا کنید:**
   ```bash
   chmod +x .run.sh
   ./.run.sh
   ```

۴. **دستورالعمل‌های روی صفحه را دنبال کنید** تا سرورتان پیکربندی شود.

---

## 🧩 پیکربندی

اسکریپت می‌تواند مقدار رم را به‌عنوان آرگومان دریافت کند. برای مثال:

```bash
./.run.sh 4G
```

همچنین می‌توانید مقدار رم را با استفاده از متغیر محیطی `ENV_MAX_RAM` تنظیم کنید.

---

## ⚠️ نکات مهم

- این اسکریپت عمدتاً برای توزیع‌های لینوکسی که از `apt-get` استفاده می‌کنند طراحی شده است؛ اجرای مستقیم آن در **Termux** یا **ویندوز** تضمین نمی‌شود.
- پیش از اجرای سرور، **توافق‌نامه کاربر نهایی (EULA)** ماینکرفت را مطالعه کنید.
- سیستم و نرم‌افزار سرور خود را همیشه به‌روز نگه دارید.
- سازگاری جاوا به نسخه ماینکرفت و پکیج‌های جاوای موجود در سیستم شما بستگی دارد.
